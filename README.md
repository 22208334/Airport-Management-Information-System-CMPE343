# Airport Management Information System - CMPE343

This repository contains the term project for **CMPE343 - Database Management Systems and Programming I**.

The project focuses on designing and implementing a relational database management system for an **Airport Management Information System**. The system stores, organizes, manipulates, and retrieves airport-related information such as airplanes, hangars, employees, technicians, traffic controllers, tests, maintenance records, and airplane locations.

---

## Project Objective

The main objective of this project is to design a real-life relational database system for airport management operations.

The database is designed to manage:

- Airplane information
- Plane models and capacities
- Hangar information
- Airplane location history
- Airport employees
- Technicians and their expertise areas
- Traffic controllers
- Maintenance and test records
- SQL queries for management and statistical analysis
